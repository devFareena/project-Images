Images


A PNG (Portable Network Graphic) file is a widely used raster image format known for supporting lossless compression and transparent backgrounds.


A JPG (or JPEG) image is a widely used, compressed raster file format developed by the Joint Photographic Experts Group in 1992.


GIF is short for Graphics Interchange Format. It is a bitmap image format developed by CompuServe in 1987, designed for images and short, looping, soundless animations commonly used online. The format supports up to 256 colors and is popular for sharing reactions, memes, and short video clips.
